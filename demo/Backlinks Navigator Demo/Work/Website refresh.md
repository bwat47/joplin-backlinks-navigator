# Website refresh

Make the neighborhood website easier to scan on a phone and easier to maintain between events.

## Content

The first page should answer what is happening, where it is, and how to join. Use the [community workshop](Community%20workshop.md) as the first content example.

## Design

Follow the [accessible writing](../Knowledge/Accessible%20writing.md) notes and keep the page structure predictable. The [design review](Review.md) records the next decisions.

## Delivery

Start with text and navigation. Photography can wait until the new structure feels settled.
