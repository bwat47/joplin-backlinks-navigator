# Note-taking habits

A useful note should make the next conversation or decision easier.

## Capture

Write enough context to understand the note a month later. Use a title that describes the topic rather than the date alone.

## Connect

Link a new idea to one existing note when there is a real relationship. The [weekly review](../Personal/Weekly%20review.md) is a good time to notice missing connections.

## Prune

Keep experiments small. Move settled material into the archive when it no longer needs regular attention.
